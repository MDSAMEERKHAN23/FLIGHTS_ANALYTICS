  Flight Analytics Dashboard – Microsoft Excel

 Project Overview

This project is an interactive Flight Analytics Dashboard built entirely in Microsoft Excel. The dashboard was designed to transform raw flight data into meaningful insights related to airline performance, ticket pricing, flight duration, departure patterns, destinations, stops, and travel classes.

The goal of this project was to demonstrate how Excel, DAX, data analysis, and data visualization can be combined to create a professional business intelligence dashboard.

---

  Dashboard Overview

The dashboard provides a consolidated view of key flight metrics, including:

- Total Number of Flights: 300,153
- Average Ticket Price: ₹20,890
- Average Flight Duration: 12.2 hours

It also includes multiple visualizations for detailed analysis.

 Airline Analysis
- Total number of flights operated by each airline
- Comparison of flight volumes across airlines
- Average ticket price for each airline

 Flight Pattern Analysis
- Flight distribution by departure time
- Analysis of morning, afternoon, evening, and night flights
- Flight analysis based on the number of stops

 City & Travel Analysis
- Number of flights by destination city
- Distribution of flights across different travel classes
- Comparison of business and economy class flights

Key Calculations

---

 Key Insights

The dashboard makes it easier to identify:

- Which airlines have the highest number of flights
- Differences in average ticket prices between airlines
- How flight volumes vary by departure time
- Which cities have the highest flight activity
- How flights are distributed according to the number of stops
- The distribution of passengers/flights across travel classes

---

 Project Objective

The main objective of this project was to practice and demonstrate real-world data analysis using Microsoft Excel.

This project focuses on converting raw data into an interactive dashboard that allows users to quickly understand important patterns and metrics without manually analyzing thousands of records.
